# Fuentes técnicas

Material propio de síntesis y ejemplos; no se reproducen pasajes extensos de las especificaciones. OSI se utiliza como mapa didáctico aproximado. Las RFC base pueden tener actualizaciones y erratas.

| Lección | Referencia primaria |
| --- | --- |
| TCP | [RFC 9293](https://www.rfc-editor.org/rfc/rfc9293.html) |
| DNS | [RFC 1034](https://www.rfc-editor.org/rfc/rfc1034.html), [RFC 1035](https://www.rfc-editor.org/rfc/rfc1035.html) |
| HTTP | [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html), [RFC 9112](https://www.rfc-editor.org/rfc/rfc9112.html) |
| TLS 1.3 / HTTPS | [RFC 8446](https://www.rfc-editor.org/rfc/rfc8446.html), RFC 9110 |
| UDP | [RFC 768](https://www.rfc-editor.org/rfc/rfc768.html) |
| DHCPv4 | [RFC 2131](https://www.rfc-editor.org/rfc/rfc2131.html), [RFC 2132](https://www.rfc-editor.org/rfc/rfc2132.html) |
| ARP | [RFC 826](https://www.rfc-editor.org/rfc/rfc826.html) |
| ICMPv4 | [RFC 792](https://www.rfc-editor.org/rfc/rfc792.html) |
| IPv4 / routers | [RFC 791](https://www.rfc-editor.org/rfc/rfc791.html), [RFC 1812](https://www.rfc-editor.org/rfc/rfc1812.html) |
| QUIC | [RFC 9000](https://www.rfc-editor.org/rfc/rfc9000.html), [RFC 9001](https://www.rfc-editor.org/rfc/rfc9001.html), [RFC 9002](https://www.rfc-editor.org/rfc/rfc9002.html) |
| IPv4 sobre Ethernet | [RFC 894](https://www.rfc-editor.org/rfc/rfc894.html); aprendizaje de bridges: IEEE 802.1Q |

Las preguntas y casos prácticos son ficticios. Se han evitado conclusiones como «ping prueba el servicio», «timeout prueba bloqueo» o «ACK TCP aprueba una operación». Ninguna de estas inferencias se sostiene sin pruebas adicionales.
